# After Nine — Shopify theme

A minimal Online Store 2.0 theme for [After Nine](https://afterninegolf.store).

The theme files live at the top of this branch (`layout/`, `sections/`, `snippets/`,
`templates/`, `assets/`, `config/`, `locales/`), so it can be connected in Shopify under
**Online Store → Themes → Add theme → Connect from GitHub**. Pushes to the connected branch
update the theme automatically, and edits made in the theme editor are committed back.

- `mockup/` holds the original static homepage mockup (not part of the theme).
- `.claude/skills/` holds design skills for Claude Code (not part of the theme).
